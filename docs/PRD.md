## 1. 한 줄 서비스 정의

K-Manner Speech는 외국인 한국어 학습자가 AI 페르소나와 텍스트 또는 음성으로 대화하며, 상대와의 관계·상황·목적에 맞는 한국어 표현과 매너를 연습하는 AI 회화 학습 서비스다.

## 2. 문제와 목표

문법적으로 맞는 문장도 관계와 상황에 따라 무례하거나 부자연스럽게 들릴 수 있다. 학습자는 실제 대화 전에 이를 안전하게 연습하고, 자신의 표현이 상대에게 줄 수 있는 인상과 더 적절한 대안을 구체적으로 확인할 수 있어야 한다.

MVP의 목표는 다음과 같다.

- 관계·상황·목적이 유지되는 AI 대화를 제공한다.
- 사용자의 표현을 높임말·예의·맥락·자연스러움 관점에서 코칭한다.
- 감정·인상 분석을 사실이 아닌 AI의 추정으로 명확히 전달한다.
- 음성 기능 일부가 실패해도 가능한 텍스트 학습 흐름은 유지한다.
- 이력서·개인 자료를 사용한 면접 연습에서 목적 고지, 확인, 수정, 삭제 권리를 보장한다.

## 3. 대상 사용자

### 3.1 핵심 사용자

- 문법 지식은 있지만 관계와 상황에 맞는 표현을 연습하려는 외국인 한국어 학습자
- 한국 생활, 학교, 직장 또는 면접에서 높임말·예의·자연스러운 표현이 필요한 학습자
- 텍스트와 음성 중 자신에게 편한 방식으로 반복 연습하려는 학습자

### 3.2 핵심 사용자 과업

1. 학습 목적과 입력 방식을 정한다.
2. 자유 채팅, 기본 상황 또는 면접 시나리오를 선택한다.
3. 관계·상황·목표를 확인하고 대화한다.
4. 발화별 피드백과 감정·인상 추정을 확인한다.
5. 추천 표현으로 다시 말하거나 같은 상황에 재도전한다.

## 5. 공통 제품 원칙

- 평가는 비난이 아닌 코칭으로 표현하며, 문제를 제시할 때 이유와 대안 표현을 함께 제공한다.
- 감정 분석은 `AI가 추정한 감정`, `이렇게 들릴 수 있어요`처럼 추정임을 표시한다.
- 성격, 정신 건강, 진실 여부 등 민감한 속성을 추론하지 않는다.
- 기술명보다 사용자의 행동과 결과를 설명한다.
- 핵심 비즈니스 판단, 인증·권한과 사용자 소유 데이터 접근은 서버에서 수행한다.
- 비밀값과 개인정보를 사용자 오류, 로그, 문서에 노출하지 않는다.
- 복합 AI 처리에서는 부분 성공을 허용하며 한 기능의 실패를 전체 대화 실패로 취급하지 않는다.
- 모든 핵심 기능은 정상·경계·실패 완료 기준을 충족해야 한다.

## 6. 기능별 요구사항과 완료 기준

### FR-01. 온보딩

**요구사항**  
사용자는 최소 정보로 학습 환경을 정한다. 이력서와 개인정보는 온보딩에서 강제로 요구하지 않는다.

**완료 기준**

- 정상: 사용자가 한국어 수준, 학습 목적, 자주 만나는 관계, 선호 입력 방식, 음성 자동 재생 여부를 선택하면 이후 연습에 선택값이 반영된다.
- 경계: 선택 가능한 값이 아직 없거나 사용자가 선택을 건너뛸 수 있는 항목은 기본값 또는 `나중에 설정`으로 명확히 처리한다. 필수 여부는 항목별로 표시한다.
- 실패: 저장이 실패해도 입력값을 보존하고 재시도할 수 있다. 서버가 허용하지 않는 값은 저장하지 않고 해당 항목을 구체적으로 안내한다.

### FR-02. 연습 유형 선택과 준비

**요구사항**  
사용자는 자유 채팅, 기본 상황 시나리오 1개, 이력서 기반 면접 시나리오 1개 중 하나를 선택한다. 시작 전에 관계, 상황, 목표, 성공 조건, 예상 시간, 입력 방식과 개인 자료 사용 여부를 확인한다.

**완료 기준**

- 정상: 세 유형이 서로 구분되고, 선택한 유형의 관계·상황·목표를 확인한 뒤 연습을 시작할 수 있다. 진행 중인 연습에는 `이어하기`가 제공된다.
- 경계: 로그인이 필요한 연습은 핵심 관계와 학습 목적을 읽을 수 있으며, 잠금 이유와 로그인이라는 다음 행동을 함께 안내한다.
- 실패: 시나리오 정보를 불러오지 못하면 빈 카드나 무반응 상태 대신 실패 원인 범주와 재시도를 제공하고, 사용할 수 있는 다른 연습 유형은 유지한다.

### FR-03. 대화 맥락 유지

**요구사항**  
AI는 선택된 관계, 상황, 대화 목적과 최근 대화 맥락에 맞게 응답한다.

**완료 기준**

- 정상: 같은 대화 세션 안에서 AI 응답과 피드백이 준비 단계에서 확인한 관계·상황·목적을 기준으로 생성된다.
- 경계: 자유 채팅처럼 관계나 목적이 명시되지 않은 경우, 설정되지 않은 맥락을 임의의 사실로 단정하지 않는다.
- 실패: 필수 맥락을 불러오지 못하면 잘못된 관계로 대화를 진행하지 않고, 사용자가 맥락을 다시 확인하거나 연습을 재시작하도록 안내한다.

### FR-04. 텍스트 대화

**요구사항**  
사용자는 텍스트를 전송하고 AI의 텍스트 응답을 읽으며 연속 대화할 수 있다.

**완료 기준**

- 정상: 유효한 텍스트를 전송하면 전송 중, 전송 완료, 응답 생성 중, 응답 완료 상태가 구분되고 AI 텍스트 응답이 대화에 추가된다.
- 경계: 빈 값 또는 공백만 있는 입력은 전송하지 않는다. 여러 줄 입력을 허용하고 입력 내용이 5줄을 넘으면 입력 영역 내부에서 확인할 수 있다.
- 실패: AI 응답이 시간 초과 또는 실패하면 사용자 입력을 보존하고 같은 발화의 재시도를 제공한다. 내부 오류나 민감한 정보를 노출하지 않는다.

### FR-05. 음성 입력(STT)

**요구사항**  
사용자는 음성을 텍스트로 변환하고 결과를 확인·수정한 뒤 전송할 수 있다.

**완료 기준**

- 정상: 마이크 권한이 있는 지원 환경에서 녹음 시작, 듣는 중, 변환 중, 확인 상태가 구분되며 변환 텍스트를 수정하고 전송할 수 있다. 전송 메시지에는 음성 입력임이 표시된다.
- 경계: 인식 결과가 없거나 신뢰하기 어려운 경우 자동 전송하지 않고 재녹음 또는 텍스트 입력을 선택할 수 있다.
- 실패: 권한 거부 또는 Web Speech API 미지원 시 이유와 텍스트 입력 대체 경로를 즉시 제공한다. 실패한 음성을 성공한 것처럼 표시하지 않는다.

### FR-06. 음성 출력(TTS)

**요구사항**  
AI 응답은 텍스트와 TTS 음성으로 제공하며 사용자가 재생을 제어할 수 있다.

**완료 기준**

- 정상: AI 텍스트 표시 직후 자동 재생을 시도하고, 재생·일시정지·처음부터 다시 듣기와 현재 재생 상태를 제공한다.
- 경계: 자동 재생이 차단되면 `눌러서 답변 듣기`를 제공한다. 사용자가 자동 재생을 끄거나 음소거하면 이후 응답에도 선택을 유지한다. 동시에 두 메시지를 재생하지 않는다.
- 실패: TTS 생성 또는 재생이 실패해도 AI 텍스트와 가능한 피드백은 유지하고 다시 시도할 수 있다.

### FR-07. 표현 평가와 코칭

**요구사항**  
각 사용자 발화에는 높임말·존댓말, 예의와 배려, 맥락 적합성, 자연스러움의 네 항목 평가와 실행 가능한 대안이 제공된다.

**완료 기준**

- 정상: 네 항목의 항목명과 점수, 종합 점수, 한 줄 요약, 잘한 점, 개선할 점, 원래 표현, 추천 표현, 관계·맥락상 추천 이유, `추천 표현으로 다시 말하기`가 제공된다.
- 경계: 개선할 내용이 적더라도 잘한 점과 맥락 설명을 유지한다. 점수는 숫자만 또는 색상만으로 전달하지 않고 해석을 함께 제공한다.
- 실패: 점수 산정에 실패하면 임의 점수를 만들지 않는다. 생성 가능한 설명형 피드백만 제공하며, 피드백 전체가 실패하면 대화는 유지하고 재시도를 제공한다.

### FR-08. 감정·인상 분석

**요구사항**  
사용자의 텍스트 또는 음성에서 추정한 감정과 상대가 받을 수 있는 인상을 학습 정보로 제공한다.

**완료 기준**

- 정상: `AI가 추정한 감정과 인상`임을 명시하고 주요 감정을 최대 3개까지 비율과 함께 제공한다. 음성 분석은 톤·속도·강세 등의 관찰 근거를, 텍스트 분석은 텍스트 근거만 사용한다.
- 경계: 결과가 불확실하거나 사용자가 다르게 느끼는 경우 단정하지 않고 `내 의도와 달라요` 피드백 경로를 제공한다.
- 실패: 분석 실패 시 감정값을 임의 생성하지 않고 `neutral` 표시 원칙을 적용한다. 대화와 표현 피드백은 가능한 범위에서 유지한다.

### FR-09. 페르소나 감정 반응

**요구사항**  
동일한 AI 페르소나는 분석 결과에 따라 사전 검수된 네 감정 이미지를 사용한다.

**완료 기준**

- 정상: 시작 전에는 `neutral`을 표시하고 AI 응답의 감정이 확정되면 `neutral`, `happy`, `sad`, `angry` 중 하나로 전환한다. 한 AI 메시지 중 표정은 한 번만 확정된다.
- 경계: 모호함, 허용되지 않은 값, 분석 중 또는 분석 실패는 `neutral`로 처리한다. 감정은 색상만이 아니라 표정과 텍스트 라벨로 구분한다.
- 실패: 해당 감정 이미지가 없거나 로드에 실패하면 `neutral`로 복귀한다. 기본 이미지도 실패하면 실루엣, 페르소나 이름과 감정 라벨을 제공한다.

### FR-10. 이력서 기반 면접 연습

**요구사항**  
사용자는 이력서·개인 자료를 제공해 자신의 정보에 근거한 면접 시나리오를 연습할 수 있다.

**완료 기준**

- 정상: 업로드 전에 허용 형식, 최대 크기, 이용 목적, 보관 기간과 삭제 방법을 확인할 수 있다. 처리 완료 후 추출 정보를 사용자가 확인·수정하고 면접 연습을 시작할 수 있다.
- 경계: 검색 결과가 없거나 추출 정보가 일부 누락되면 이를 표시하고 사용자가 수정·보완하거나 개인화 없이 진행할 선택지를 제공한다.
- 실패: 미지원 형식, 크기 초과, 업로드 또는 처리 실패를 구분해 안내하고 재시도 또는 파일 교체를 제공한다. 실패한 자료로 면접 내용을 생성하지 않는다.
- 개인정보: 자료와 생성된 시나리오를 삭제할 수 있고, 다른 사용자의 시나리오에 쓰인다는 인상을 주지 않으며, 홈 미리보기에서 민감 내용을 노출하지 않는다.

### FR-11. 결과와 복습

**요구사항**  
대화가 끝나면 학습 결과를 요약하고 즉시 재연습할 수 있어야 한다.

**완료 기준**

- 정상: 종합 점수, 네 항목 점수, 잘한 표현, 고쳐볼 표현 최대 3개, 감정·인상 요약, 대화 목표 달성 여부, 다시 말하기와 같은 상황 재도전을 제공한다.
- 경계: 일부 분석만 성공한 경우 성공한 결과를 먼저 제공하고 누락 항목을 명확히 표시한다. 점수가 없는 항목을 0점으로 표시하지 않는다.
- 실패: 결과 생성이 실패해도 완료된 대화 기록과 사용자 입력을 잃지 않으며 재시도를 제공한다.

### FR-12. 접근성·반응형·상태 처리

**요구사항**  
MVP는 반응형 웹과 모바일 앱에서 같은 정보 구조를 제공하며 WCAG 2.2 AA를 목표로 한다.

**완료 기준**

- 정상: 모든 핵심 동작을 키보드로 수행할 수 있고 포커스가 보인다. 일반 텍스트 대비 4.5:1, 큰 텍스트·핵심 그래픽 3:1, 터치 대상 44×44px 이상, 텍스트 200% 확대 조건을 충족한다.
- 경계: 감정·점수·상태를 색상만으로 전달하지 않으며, 음성에는 동일한 텍스트, 이미지에는 역할과 감정을 설명하는 대체 텍스트를 제공한다. 동작 감소 설정에서는 반복 모션을 제거한다.
- 실패: 오프라인, 시간 초과, 부분 성공, 빈 상태와 오류 상태에는 현재 상태와 재시도 또는 대체 경로가 제공된다. 오류가 사용자의 탓이라고 단정하지 않는다.

## 7. 핵심 사용자 흐름

### 7.1 일반 회화

온보딩 또는 기존 설정 확인 → 자유 채팅/기본 상황 선택 → 관계·상황·목표 확인 → 텍스트 또는 음성 발화 → AI 텍스트 응답 → TTS 재생 시도 → 발화별 피드백·감정 추정 확인 → 추천 표현 다시 말하기 → 결과·재도전

### 7.2 이력서 기반 면접

면접 연습 선택 → 자료 이용 목적·정책 확인 → 파일 업로드 → 처리 상태 확인 → 추출 정보 확인·수정 → 면접 맥락 확인 → 대화 → 발화별 코칭 → 결과 확인 → 자료 또는 생성 시나리오 삭제

## 8. 비기능 제품 요구사항

- 보안·권한: 인증과 사용자 소유 데이터 접근은 서버에서 검증하며 요청에 포함된 사용자 식별자를 그대로 신뢰하지 않는다.
- 개인정보: 필요 최소한만 수집하고 목적, 보관 기간, 삭제 방법을 고지한다. 비밀값과 개인정보를 오류나 로그에 노출하지 않는다.
- 복원력: 외부 AI, 음성 또는 이미지 기능 실패 시 성공한 결과와 사용자 입력을 보존한다.
- 일관성: 동일 개념에는 동일 용어를 사용하고 감정 상태는 네 값으로 정규화한다.
- 검증성: 각 요구사항은 외부에서 관찰 가능한 정상·경계·실패 기준으로 검수한다.

## 9. 이번에 만들지 않을 것

- 시나리오·페르소나 유사도 검색 및 검색 UI
- 대화 중 실시간 페르소나 이미지 생성
- `neutral`, `happy`, `sad`, `angry` 외의 세분화된 페르소나 감정 이미지
- 실제 인물·유명인 모사 또는 권리·동의가 불명확한 참조 이미지 사용
- 성격, 정신 건강, 진실 여부 등 민감 속성 추론
- 문서 근거 없이 추가하는 결제·구독 또는 무료/프리미엄 구분
- 문서 근거 없이 추가하는 소셜 기능, 랭킹, 게임화, 다수의 신규 시나리오
- 구현 기술 변경, API 계약, 화면 상세 설계, 데이터베이스 설계

## 11. 출시 판정 기준

MVP 출시는 다음을 모두 만족할 때 승인한다.

- FR-01~FR-12의 정상·경계·실패 기준이 검수되고 미충족 항목이 공개되어 있다.
- 자유 채팅, 기본 상황 1개, 이력서 기반 면접 1개의 시작부터 결과·재도전까지 핵심 흐름이 연결된다.
- AI·STT·TTS·감정 분석·이미지 중 하나가 실패해도 가능한 텍스트 학습 결과와 입력이 보존된다.
- 개인정보의 수집 목적, 보관 기간, 삭제 방법이 확정·고지되고 사용자 소유 데이터 접근이 보호된다.
- 접근성 목표와 핵심 예외 상태가 검수된다.
- 범위 밖 기능이 MVP에 포함되지 않는다.
